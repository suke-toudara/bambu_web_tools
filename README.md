# Bambu Web Tools

3D モデル(STEP/STL/OBJ/3MF)の表示・配置・スライス・Bambu Lab プリンターへの印刷までをブラウザだけで行う Next.js 製ツールです。
[bambu-printer-mcp](https://github.com/DMontgomery40/bambu-printer-mcp) と
[mcp-3D-printer-server](https://github.com/DMontgomery40/mcp-3D-printer-server) の実装を参考に、
Bambu Lab の LAN モード通信プロトコル(MQTT + FTPS)を直接実装しています。

## 機能

- **表示**: STEP (.step/.stp) を [occt-import-js](https://github.com/kovacsv/occt-import-js)(OpenCascade の WASM ビルド)で、STL/OBJ/3MF を three.js 標準ローダーでブラウザ上に読み込み、3D 表示します。複数ファイル・複数フォーマットを混在させて追加でき、STEP のマルチボディアセンブリや 3MF の複数オブジェクトプレートは自動的に個別パーツへ分解されます。
- **マルチパーツプレート編集**: 追加したパーツはプレート上に自動配置(重ならないよう棚詰め配置)され、クリックで選択してビューア上でハイライト表示。位置・回転・スケールを数値入力で個別に調整でき、「ベッドに接地」ボタンで底面をプレートに合わせ直せます。手動で位置を調整して他のパーツと重なった場合は、ビューア(赤い枠)・パーツ一覧・スライスパネルの3箇所でリアルタイムに警告表示されます。
- **スライス**: サーバー側で独自実装した簡易スライサーが、平面交差によるレイヤー輪郭抽出 → 壁(パーリメーター)オフセット → ジグザグインフィル → 上下ソリッド層 → (任意で)オーバーハング下へのサポート柱自動生成、という手順で G コードを生成します。複数パーツが乗ったプレート全体を 1 回のスライスでまとめて処理します。レイヤーごとのプレビュー(壁=青緑、サポート=オレンジ)、推定印刷時間・フィラメント使用量も表示します。
- **印刷**: Bambu Lab プリンター(LAN モード)へ
  - 生成した G コードをそのまま送信する「簡易印刷」(単色・AMS 不使用、`gcode_file` コマンド)
  - Bambu Studio / OrcaSlicer で書き出した `*.gcode.3mf` を送信する「本印刷」(`project_file` コマンド、AMS マッピング対応)
  の両方に対応。ステータスは「③ プリンターへ送信」タブを開いている間 5 秒ごとに自動更新され(チェックボックスでオフ可)、一時停止/再開/停止も可能です。

### サポート材について

「ビルドプレート接地のみ」モードのみ対応の簡易実装です。各 XY 位置で仮想的な垂直レイを飛ばし、モデルの最下層のソリッド区間の底面がプレートに接地していない(=浮いている)かつオーバーハング角度のしきい値を超えている場合に、プレートからその底面直下までの角柱サポートを生成します。モデル自身の上に乗るタイプのサポート(ツリーサポート等)は生成しません。

## 技術的な制約(重要)

Bambu Lab のスライサー(BambuStudio/OrcaSlicer)は、ノズル/ベッド専用の校正マクロや開始 G コード、AMS
フィラメントデータベースなどプロプライエタリな要素に強く依存しており、これをブラウザ上で完全に再現することは
現実的ではありません([bambu-printer-mcp のスライスに関するドキュメント](https://github.com/DMontgomery40/bambu-printer-mcp/blob/main/docs/SLICING.md)
参照)。そのため本ツールでは:

- 内蔵スライサーは **単色・AMS 非対応の簡易実装**(壁+ジグザグインフィル+簡易サポートのみ、専用開始 G コードなし)です。
  P1 / A1 / X1 系プリンターの `gcode_file` コマンドで送信できる、簡単な単色プリント向けです。
- **フル機能(AMS、フロー校正、機種別開始 G コード)が必要な場合**は、Bambu Studio / OrcaSlicer で
  スライスして「Export → Export plate sliced file」で書き出した `*.gcode.3mf` を、本ツールの
  「事前スライス済みファイルを印刷」機能から送信してください。こちらはベンダースライサーの出力をそのまま
  使うため、AMS マッピングや校正を含むフル機能の印刷が可能です。
- **H2 シリーズ(H2S/H2D/H2C)は非対応**です。2025年以降のファームウェアは Bambu 発行のクライアント証明書による
  mTLS が必須であり、本ツールは実装していません。P1/A1/X1 系の LAN モードを前提としています。

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。

### プリンター接続情報の確認方法

Bambu Lab プリンターの `設定 > WLAN` (または LAN 設定画面)から以下を確認してください。

- **IP アドレス**: プリンター本体のネットワーク設定画面に表示
- **シリアル番号**: 本体設定 or 底面ラベル
- **アクセスコード**: LAN モードのアクセスコード(本体設定画面に表示)

いずれもブラウザの `localStorage` にのみ保存され、外部には送信されません(印刷 API を呼び出す際にサーバーへ
渡り、そのままプリンターへの MQTT/FTPS 接続に使われます)。

### 複数プリンターの登録

「③ プリンターへ送信」タブでは、名前を付けて複数のプリンター接続情報を保存できます。

- IP/シリアル/アクセスコードを入力し、名前を付けて「新規に保存」すると登録されます。
- 登録済みのプリンターはチップとして表示され、クリックすると入力欄がそのプリンターの情報に切り替わります。
- 選択中のプリンターの接続情報を書き換えた場合は「現在の接続で上書き」で保存内容を更新できます。
- チップの ✕ で削除できます。
- 登録内容・最後に選択していたプリンターはブラウザを閉じても保持されます。

## ディレクトリ構成

```
src/
  app/
    page.tsx              # メイン UI (モデル配置 → スライス → 印刷)
    api/slice/             # スライス API (STL → Gコード)
    api/printer/           # Bambu プリンター制御 API (status/print-gcode/print-project/control)
  components/
    ModelViewer.tsx        # three.js ベースの 3D ビューア (マルチパーツ・選択・ハイライト対応)
    PartList.tsx           # パーツ一覧・位置/回転/スケール編集 UI
    LayerPreview.tsx       # レイヤー輪郭プレビュー (canvas, 壁/サポート色分け)
  lib/
    occt/                  # occt-import-js (STEP パース) ラッパー
    loaders/                # STEP/STL/OBJ/3MF 統一ローダー (PlacedPart[] を生成)
    scene/                  # マルチパーツのプレート配置・変形・重なり判定・エクスポート
    stl/                   # STL の読み書き
    slicer/                # 独自スライスエンジン (平面交差・オフセット・インフィル・サポート・Gコード生成)
    printer/bambu/         # Bambu LAN プロトコル (MQTT ステータス/制御, FTPS アップロード, 印刷開始)
public/wasm/                # occt-import-js の WASM 本体 (クライアントから直接 fetch)
```

## 既知の制限

- スライサーはポリゴンオフセットを簡易的な miter 法で行っているため、非常に鋭い凹角形状では壁がわずかに乱れる
  ことがあります。
- サポート材は「ビルドプレート接地のみ」の角柱サポートのみ対応です。ツリーサポートやモデル自身の上に乗る
  サポートには対応していません。
- ブリム/ラフト、可変レイヤー高さには対応していません。
- パーツの自動配置は単純な棚詰め(左詰め・行送り)方式で、真のビンパッキングではありません。
- 重なり検出はワールド座標系での軸並行バウンディングボックス(AABB)判定です。回転したパーツ同士では、実際の
  形状同士は接していなくてもバウンディングボックスが重なって警告が出ることがあります(安全側の簡易判定)。
- OBJ の MTL(マテリアル)ファイルには対応していません(ジオメトリのみ読み込み、色は既定パレットを使用)。
- 三角形数が非常に多い(40万を超える)メッシュはスライス API 側で拒否されます。事前に簡略化してください。
